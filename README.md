## CheapAssGas city outlook

A mobile-first dashboard prototype for exploring city fuel prices, historic trends, daily outlook scenarios, market and media signals, and a city price map.

### Run locally

Serve the project root with any static HTTP server, or open `index.html` directly in a browser.

### Data status

Prices, historical series, city comparisons, market signals, and outlooks are illustrative sample data. They are labeled in the UI and are not live station quotes. The location button selects the nearest supported sample city using browser geolocation; the map itself is a lightweight US overview. Connect trusted sources such as EIA for fuel and crude history, an equity data provider, and a news trend feed before using this as a live forecasting product.
